## 什么是 BotBlocker？

**BotBlocker Security 在 WordPress 加载之前就能阻止 99% 的自动化攻击。** 无冗余、无延迟、核心保护无月费。60 秒完成设置。

三道拦截层在 `wp-config.php`（WordPress 之前）、MU-plugin 阶段和主防护盾处拦截恶意流量--每个被阻止的请求节省 30–100ms 和 5–20MB RAM。竞品在 WordPress 启动后才反应；BotBlocker 将威胁挡在门外。

**3,000+ 活跃安装 · 8 种语言 · 符合 GDPR/CCPA · 兼容 Cloudflare、WP Rocket、LiteSpeed、WooCommerce、Elementor、多站点、IPv6**

## 核心功能

### 🛡️ 核心防火墙（免费）
- **三道防火墙**，实时 WAF 规则更新
- **2,899 条 User-Agent 签名** - WordPress 插件中最大的黑名单
- **暴力破解防护**，渐进式锁定和升级封禁
- **反垃圾评论**，覆盖评论、注册和联系表单
- **伪造爬虫检测** 通过 FCrDNS - 95% 有效，无法伪造
- **LLM/AI 爬虫管理** - 允许或阻止 GPTBot、ClaudeBot、PerplexityBot、Bytespider
- **按国家、ASN、IP 范围、User-Agent、Referer 拦截**
- **Cloudflare 兼容** - 真实 IP 解析和源站绕过保护
- **完整 IPv6 支持** - IPv4 和 IPv6 独立表结构和逻辑
- **DDoS 防护自动检测** - 识别 DDoS-Guard、Stormwall、Qrator 的 JS 挑战。唯一无需手动白名单即可在激进 DDoS 防护后正常工作的 WordPress 插件

### 🔒 登录安全与双因素认证（免费）
- **双因素认证 (2FA)** - TOTP 标准（兼容 Google Authenticator、Authy、Bitwarden）
- **9 种验证码模式** - 静默自动验证、Shapes（60fps Canvas）、颜色、图片、数字、长按按钮、单击按钮、reCAPTCHA v2/v3
- **混合验证码** - 内部验证码与 reCAPTCHA v3 结合，双层防御
- **隐藏登录 URL** *(PRO)*

### 💳 支付网关绕过（免费）
自动检测 25+ 电商平台和 150+ 支付服务商（Stripe、PayPal、WooCommerce 等）。Webhook 和 IPN 回调永远不会被拦截。

### 📊 可见性与控制（免费）
- 实时流量监控，包含攻击地图和 54 种唯一事件代码
- 健康评分仪表 - 42 项参数，5 个安全等级
- 8 种界面语言 - English、Deutsch、Español、Français、Polski、Русский、Українська、中文
- 干净卸载 - 零残留数据

## 技术栈

- **PHP** 7.4–8.5
- **WordPress** 5.1–7.0+
