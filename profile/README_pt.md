## O que é o BotBlocker?

**O BotBlocker Security bloqueia 99% dos ataques automatizados antes mesmo do WordPress carregar.** Sem inchaço, sem lentidão, sem taxas mensais para a proteção principal. Configuração em 60 segundos.

Três camadas de interceptação param o tráfego malicioso no `wp-config.php` (antes do WordPress), na fase de MU-plugin e no escudo principal - economizando 30–100ms e 5–20MB de RAM por requisição bloqueada. Os concorrentes reagem depois que o WordPress inicializa; o BotBlocker para as ameaças na porta.

**3.000+ instalações ativas · 8 idiomas · Em conformidade com GDPR / CCPA · Compatível com Cloudflare, WP Rocket, LiteSpeed, WooCommerce, Elementor, multisite, IPv6**

## Principais Funcionalidades

### 🛡️ Firewall Principal (Grátis)
- **Firewall de três camadas** com atualizações de regras WAF em tempo real
- **2.899 assinaturas de User-Agent** - a maior lista negra entre os plugins WordPress
- **Proteção contra força bruta** com bloqueios progressivos e bans escalonados
- **Anti-spam** para comentários, registros e formulários de contato
- **Detecção de rastreadores falsos** via FCrDNS - 95% eficaz, impossível de falsificar
- **Gerenciamento de rastreadores LLM / IA** - permitir ou bloquear GPTBot, ClaudeBot, PerplexityBot, Bytespider
- **Bloqueio por país, ASN, faixa de IP, User-Agent, Referer**
- **Compatível com Cloudflare** - resolução de IP real e proteção contra bypass de origem
- **Suporte completo a IPv6** - tabelas e lógica separadas para IPv4 e IPv6
- **Detecção automática de DDoS** - reconhecimento de JS-challenge para DDoS-Guard, Stormwall, Qrator. O único plugin WordPress que funciona atrás de proteção DDoS agressiva sem whitelist manual

### 🔒 Segurança de Login e 2FA (Grátis)
- **Autenticação de Dois Fatores** - padrão TOTP (Google Authenticator, Authy, Bitwarden)
- **9 modos de CAPTCHA** - Silent Auto-Verify, Shapes (Canvas 60fps), Colors, Images, Digits, Hold Button, Single Button, reCAPTCHA v2/v3
- **CAPTCHA Híbrido** - combina CAPTCHA interno com reCAPTCHA v3 para defesa em duas camadas
- **Ocultar URL de login** *(PRO)*

### 💳 Bypass de Gateways de Pagamento (Grátis)
Detecção automática de mais de 25 plataformas de e-commerce e mais de 150 provedores de pagamento (Stripe, PayPal, WooCommerce, etc.). Webhooks e notificações IPN nunca são bloqueados.

### 📊 Visibilidade e Controle (Grátis)
- Monitor de tráfego ao vivo com mapa de ataques e 54 códigos de evento únicos
- Indicador Health Score - 42 parâmetros, 5 níveis de segurança
- 8 idiomas de interface - English, Deutsch, Español, Français, Polski, Русский, Українська
- Desinstalação limpa - zero dados residuais

## Por que BotBlocker?

| | BotBlocker | Plugins de segurança típicos |
|---|---|---|
| **Ponto de interceptação** | Antes do WordPress carregar | Depois do WordPress inicializar |
| **CPU/RAM por requisição bloqueada** | 30–100ms / 5–20MB RAM economizados | Pilha completa do WordPress carregada |
| **Modos CAPTCHA** | 9 (proprietários + reCAPTCHA) | 1–2 (apenas reCAPTCHA) |
| **CAPTCHA resistente a IA** | Sim -- Shapes ~100x mais difícil de quebrar que reCAPTCHA (quebrável por $2-3/1.000) | Não |
| **Limites da versão gratuita** | Nenhum - firewall completo, todas as CAPTCHAs, 2FA completo | Recursos limitados, telas irritantes |
